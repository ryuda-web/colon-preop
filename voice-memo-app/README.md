# ボイスメモ文字起こし

iPhone のボイスメモ(.m4a)を高精度に文字起こしする PWA。OpenAI の音声認識 API
(`gpt-4o-transcribe`)を利用し、日本語の専門用語にも強い文字起こしを実現します。

## 機能

- **ファイル文字起こし**: ボイスメモから共有した音声ファイル(m4a/mp3/wav 等)を選択して文字起こし
- **その場で録音**: アプリ内マイク録音 → そのまま文字起こし
- **カスタム辞書**: 専門用語・人名・施設名を登録すると認識ヒントとして渡され、精度が大幅向上
- **長時間録音対応**: 25MB 超のファイルは端末内で 16kHz モノラルにデコード → 自動分割。
  前チャンク末尾をヒントとして次チャンクへ引き継ぎ、文脈の連続性を維持
- **AI 後処理**: 句読点・段落整形 / フィラー(えー、あのー)除去 / 要約
- **履歴**: 結果は端末内(localStorage)に最大20件保存。コピー・共有ボタン付き
- **PWA 対応**: ホーム画面に追加してアプリのように利用可能

## 精度を上げるコツ

1. **カスタム辞書に固有名詞を登録する**(最重要)— 設定画面から、よく使う専門用語・
   人名・地名を読点区切りで列挙しておくと誤変換が激減します
2. モデルは `gpt-4o-transcribe`(既定)が最高精度。コスト優先なら `gpt-4o-mini-transcribe`
3. 録音時はマイクに近づき、できるだけ静かな環境で

## 長時間録音(1時間程度)の扱い

ボイスメモ標準品質(AAC 約64kbps)はおよそ **0.5MB/分**。

| 録音時間 | サイズ目安 | 処理方法 |
|---|---|---|
| 〜約50分 | 〜24MB | そのまま1リクエストで送信(最速) |
| 50分〜 | 24MB超 | 端末内で自動分割(10分単位)→ 順次送信 |

1時間の録音なら約6チャンクに分割され、処理は全体で数分です。分割時は以下の工夫で
精度と使い勝手を確保しています:

- **16kHz で直接デコード**してメモリ使用量を約1/3に抑え、iPhone でも1時間超を安定処理
- **無音位置で分割**(境界手前30秒で最も静かな箇所を探索)— 語の途中で切れない
- 前チャンク末尾200文字を次チャンクの認識ヒントに引き継ぎ、文脈を維持
- 通信エラーは自動リトライ(2回)。それでも失敗した場合は**途中までの結果を表示**し、
  「▶︎ 残りを再開」ボタンで続きから処理できる
- 処理中は **画面スリープを自動防止**(Wake Lock)。画面は開いたままにしてください

## 必要なもの

- OpenAI API キー(https://platform.openai.com/api-keys で発行)
  - 料金目安: 約 $0.006/分(gpt-4o-transcribe)。1時間の録音で約 $0.36
  - キーは端末内(localStorage)のみに保存され、OpenAI 以外には送信されません

## iPhone ボイスメモからの取り込み手順

1. ボイスメモアプリで対象の録音を開く
2. 「…」→「共有」→「**"ファイル"に保存**」
3. このアプリで「ファイルを選択」→ 保存した場所から選ぶ

## ファイル構成

```
index.html              # アプリ本体
manifest.webmanifest    # PWA マニフェスト
sw.js                   # Service Worker (オフライン対応)
icon-192.png            # PWA アイコン
icon-512.png            # PWA アイコン
icon-maskable-512.png   # Android maskable アイコン
apple-touch-icon.png    # iOS ホーム画面アイコン
```

## デプロイ手順 (GitHub Pages)

このリポジトリの GitHub Pages が有効なら、main ブランチへマージ後
`https://<ユーザー名>.github.io/<リポジトリ名>/voice-memo-app/` で公開されます。

1. リポジトリの「Settings」→「Pages」
   - Source: **Deploy from a branch** / Branch: **main** / **/ (root)**
2. 数分待って上記 URL にアクセス
3. Safari で開き「共有」→「ホーム画面に追加」でアプリ化

## アップデート方法

コード変更時は `index.html` の `APP_VERSION` と `sw.js` の `CACHE_NAME` を更新
(例: v1.0.0 → v1.0.1)してコミット。Service Worker が自動で最新版を取得します。

## 注意事項

- 音声データは文字起こしのため OpenAI のサーバーへ送信されます。
  **患者情報・個人情報を含む録音の取り扱いは所属組織の規程に従ってください**
- OpenAI API はデフォルトでは API 経由のデータを学習に使用しませんが、
  機密性の高い用途では組織のポリシーを確認してください
- GitHub Pages の無料プランは URL が公開されます(アプリ自体は API キーがないと動作しません)
