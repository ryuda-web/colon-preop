# 術前おくすりチェッカー

君津 外科レジデント教育用の、周術期休薬日 逆算ツール（非心臓手術用）。
「大腸術前検査スケジューラ」(`../colon-preop-app`) の姉妹アプリ。

> **現在 v0.1.0-draft（監修前ドラフト）**
> 辞書内の休薬日数はガイドラインをもとにした下書きであり、原典・施設プロトコルとの照合（監修）が完了するまで実運用しないこと。

## 機能（Phase 1）

- 手術予定日・出血リスク（高/低）・区域麻酔の有無・腎機能を設定
- 内服薬をインクリメンタル検索で追加（商品名・一般名・ひらがな対応）
- 薬ごとに「○月○日(曜)から休薬（手術日を含まず○日前）／最終内服日」を逆算表示
- 日付順の休薬カレンダー表示
- カルテ貼付用テキストのコピー出力
- ブリッジング・冠動脈ステント後・区域麻酔併用は日数計算せず「要相談」フラグで返す設計
- 入力は端末内 localStorage のみに保存（患者情報は入力しない設計）
- PWA 対応／オフライン動作

## 出典の階層構成

| 層 | 出典 | 対象 |
|---|---|---|
| 基幹 | 日本循環器学会 JCS2022「非心臓手術における合併心疾患の評価と管理に関するガイドライン」 | 抗血栓薬 |
| 学会推奨 | 日本糖尿病学会「SGLT2阻害薬の適正使用に関するRecommendation」(2022改訂) | SGLT2阻害薬（術前3日） |
| 学会提言 | 日本麻酔科学会 GLP-1受容体作動薬に関する提言（ASA準拠・合同ステートメント改訂待ち） | GLP-1 |
| フラグのみ | 区域麻酔・神経ブロックGL2016 | 硬膜外・脊麻併用時の警告 |
| フォールバック | 各薬剤の電子添文（PMDA） | OC/LEP ほか |

消化器内視鏡（JGES 2012/追補2017）の休薬は**対象外**（アプリ内に明記）。

## 今後の予定

- **監修**: 全エントリ `draft:true` → 原典照合後に解除（`index.html` 内 `DRUGS` 配列）
- **Phase 2**: お薬手帳の写真から Tesseract.js（端末内OCR）で薬剤候補を自動抽出
- **Phase 3**: 画像前処理による精度改善、PTPシート対応の検討

## ファイル構成

```
index.html              # アプリ本体（辞書・ルールエンジン込み）
manifest.webmanifest    # PWA マニフェスト
sw.js                   # Service Worker (オフライン対応)
icon-*.png              # PWA アイコン
apple-touch-icon.png    # iOS ホーム画面アイコン
```

## アップデート方法

コード変更 → `index.html` の `APP_VERSION` と `sw.js` の `CACHE_NAME` を更新してコミット。
Service Worker が自動で最新版を取得。

## 注意事項

- このツールは**教育目的のダブルチェック支援**であり、休薬指示は施設プロトコル・主治医/麻酔科/処方医の判断を優先すること
- 患者情報は入力しない設計（設定と薬剤リストのみ端末内 localStorage 保存）
- GitHub Pages の無料プランは URL が公開される。限定公開が必要な場合は Cloudflare Access 等を検討
